# Instaladores do Imobius

Este repositório distribui os pacotes oficiais do tema Imobius Visual e do plugin Imobius CRM.

Os arquivos estão na área **Releases**:

- `imobius-visual.zip`: tema do WordPress.
- `imobius-crm.zip`: plugin do CRM.
- `imobius-release.json`: manifesto de integridade da versão.

Para atualizar, use o painel do WordPress ou envie os ZIPs escolhendo substituir os componentes instalados. Mantenha um backup da hospedagem antes da atualização.
